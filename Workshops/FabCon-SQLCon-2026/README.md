# From Vectors to Agents: Building AI-Powered Solutions with Microsoft SQL

This end-to-end workshop was presented at FabCon and SQLCon Europe 2026. It combines Microsoft SQL with AI techniques to demonstrate:

- Embeddings, vector similarity search, and DiskANN
- Hybrid search
- Retrieval-augmented generation (RAG)
- Agentic RAG
- Row-level security for AI applications
- SQL MCP Server and Microsoft Foundry
- Modernizing existing applications with AI
